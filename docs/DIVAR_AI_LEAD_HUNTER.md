# مشتری‌یاب هوشمند دیوار — نسخه تخصصی

## هدف
این مخزن منبع تخصصی دریافت و تحلیل آگهی‌های دیوار است. موتور عمومی AI Lead Hunter در پلتفرم مادر باقی می‌ماند؛ این پروژه مسئول داده و تحلیل اختصاصی دیوار است.

## دامنه نسخه اول
- جست‌وجو و دریافت آگهی‌های عمومی با فیلتر دسته، شهر، محدوده، قیمت و تاریخ.
- ذخیره پایدار و جلوگیری از ثبت تکراری.
- تحلیل عنوان و توضیحات آگهی برای استخراج نیاز و قصد احتمالی (خریدار، فروشنده، موجر، مستأجر، ارائه‌دهنده خدمت، متقاضی خدمت).
- امتیازدهی قابل توضیح به تناسب آگهی با کسب‌وکار تعریف‌شده.
- صف بازبینی انسانی برای سرنخ‌های باکیفیت.
- ثبت منبع، زمان مشاهده و شواهد هر نتیجه.
- خروجی اکسل/CSV و گزارش عملکرد.

## قواعد داده و ارتباط
- تحلیل فقط بر داده آگهی عمومی و داده‌ای که کاربر مجازانه ارائه کرده انجام می‌شود.
- استخراج شماره تماس مخفی، دور زدن ورود/کپچا، برداشت داده حساب‌های خصوصی و دور زدن محدودیت‌های دیوار در دامنه نیست.
- هیچ پیام خودکار یا تماس سرد از این پروژه انجام نمی‌شود. ارتباط از طریق قابلیت‌های مجاز پلتفرم و پس از بررسی انسانی/مبنای ارتباط معتبر انجام می‌شود.
- داده شخصی غیرضروری ذخیره نمی‌شود؛ لینک آگهی و شناسه منبع برای ارجاع کافی است.
- API وب دیوار در وضعیت فعلی رسمی/تضمین‌شده فرض نمی‌شود؛ تغییر ساختار یا محدودیت باید با توقف امن مدیریت شود.

## پروفایل‌های کسب‌وکار
موتور نباید فقط برای املاک نوشته شود. هر پروفایل می‌تواند شامل صنعت، کلمات کلیدی مثبت/منفی، دسته‌های هدف، مناطق، حداقل/حداکثر قیمت، ویژگی‌های لازم و وزن هر معیار باشد. پروفایل املاک دزفول اولین نمونه است.

## خروجی تحلیل هر آگهی
- intent: BUY / SELL / RENT / LEASE / SERVICE_SEEKER / SERVICE_PROVIDER / UNKNOWN
- topic/category و نیاز استخراج‌شده
- score: 0..100
- confidence: LOW / MEDIUM / HIGH
- matchedSignals و excludedSignals برای توضیح تصمیم
- requiresHumanReview: true
- sourceUrl و observedAt
