# amlak-divar

اسکریپت استخراج آگهی‌های املاک دزفول از سایت دیوار و ذخیره در فایل اکسل.

## ویژگی‌ها

- استخراج آگهی‌های **آپارتمان**، **ویلایی** و **زمین** در دزفول
- فیلتر بر اساس محله (مثلاً بهاران، فرهنگ‌شهر و ...)
- استخراج فیلدها:
  - عنوان
  - متراژ
  - قیمت کل
  - قیمت هر متر
  - سال ساخت
  - نوع آگهی‌دهنده (شخصی / مشاور املاک)
  - محله
  - لینک آگهی
- محاسبه میانگین قیمت هر متر برای هر محله
- خروجی اکسل با فرمت خوانا

## نصب

```bash
cd amlak-divar
python -m venv venv
source venv/bin/activate   # در ویندوز: venv\Scripts\activate
pip install -r requirements.txt
```

## اجرا

```bash
python scrape_dezful.py
```

یا با پارامترهای اختیاری:

```bash
python scrape_dezful.py --max-pages 5 --districts "بهاران,فرهنگ شهر"
```

## خروجی

فایل اکسل در پوشه `output/` ذخیره می‌شود:
- `dezful_amlak_YYYYMMDD_HHMM.xlsx`

شیت‌ها:
1. **همه آگهی‌ها**
2. **خلاصه قیمت مناطق** (میانگین قیمت هر متر)

## توجه

- این اسکریپت از API عمومی/غیررسمی دیوار استفاده می‌کند.
- لطفاً با فاصله زمانی مناسب اجرا کنید تا به سرور فشار وارد نشود.
- در صورت تغییر ساختار API دیوار، ممکن است نیاز به به‌روزرسانی داشته باشد.
- ابتدا با `python find_city_id.py` شناسه صحیح شهر دزفول را پیدا کنید و در اسکریپت قرار دهید.
