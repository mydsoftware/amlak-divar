# استخراج آگهی املاک دیوار - دزفول

ابزار تعاملی پایتون برای جمع‌آوری آگهی‌های آپارتمان، ویلایی و زمین دزفول و نگهداری پیوسته اطلاعات در اکسل.

## امکانات
- منوی کاملاً فینگلیش برای سازگاری با کنسول ویندوز
- ورود بازه تاریخ شمسی و تعداد آگهی
- شروع استخراج جدید یا ادامه وضعیت ذخیره‌شده
- شماره‌گذاری پیوسته آگهی‌ها
- جلوگیری از ثبت تکراری بر اساس شناسه آگهی دیوار
- ذخیره وضعیت در `data/progress.json` و امکان ادامه پس از بسته‌شدن برنامه
- افزودن اطلاعات به یک فایل اکسل ثابت و به‌روزرسانی خلاصه قیمت محله‌ها
- فیلتر اختیاری محله

## نصب در ویندوز (PowerShell)
```powershell
cd amlak-divar
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## اجرا
```powershell
python scrape_dezful.py
```

در منو:
1. شروع استخراج جدید: بازه تاریخ شمسی و تعداد را وارد کنید.
2. ادامه استخراج قبلی: تعداد آگهی جدیدی که می‌خواهید اضافه شود را وارد کنید؛ تنظیمات بازه تاریخ قبلی حفظ می‌شود.
3. نمایش آمار
4. خروج

نمونه تاریخ: `1405/08/01`

## فایل‌های خروجی
- اکسل: `output/dezful_amlak.xlsx`
- وضعیت و نقطه ادامه: `data/progress.json`

ستون‌ها و داده‌های آگهی در اکسل فارسی هستند؛ فقط پیام‌های کنسول فینگلیش‌اند.

## نکته مهم درباره تاریخ انتشار
فیلتر تاریخ فقط زمانی آگهی را می‌پذیرد که پاسخ API دیوار یک فیلد تاریخ/زمان انتشار قابل‌تشخیص داشته باشد. اگر این داده در پاسخ وجود نداشته باشد، آگهی با تاریخ نامشخص وارد اکسل نمی‌شود و تعداد آن در گزارش نمایش داده می‌شود. API دیوار رسمی و پایدار تضمین‌شده نیست و ممکن است ساختارش تغییر کند.

## محدودیت استفاده
درخواست‌ها با فاصله زمانی انجام می‌شوند. از اجرای هم‌زمان چند نسخه اسکریپت خودداری کنید.
