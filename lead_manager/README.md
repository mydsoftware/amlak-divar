# مدیریت سرنخ دیوار — نسخه پایه

نرم‌افزار دسکتاپ ویندوزی با رابط فارسی و پایگاه داده SQLite برای ساخت کمپین، هدایت جستجو به دیوار، ثبت دستی/مجاز سرنخ‌ها و خروجی Excel.

## اجرا در ویندوز
1. Python 3.10 یا جدیدتر را نصب کنید.
2. در این پوشه اجرا کنید:
   ```powershell
   python -m pip install -r requirements.txt
   python app.py
   ```
   یا روی `run_windows.bat` دوبار کلیک کنید.
3. کمپین بسازید، جستجو را در مرورگر باز کنید و فقط اطلاعات عمومی و مجاز را در بانک سرنخ ثبت کنید.
4. از تب «بانک سرنخ‌ها» خروجی Excel بگیرید.

## امکانات نسخه پایه
- چند کمپین با حوزه، شهر، کلیدواژه و متن پیشنهادی
- بازکردن جستجوی دیوار در مرورگر پیش‌فرض ویندوز
- ثبت لینک آگهی، عنوان، حوزه، شهر، راه تماس عمومی/مجاز، یادداشت و وضعیت رضایت
- جلوگیری از ثبت لینک تکراری
- مراحل پیگیری فروش
- پایگاه داده محلی SQLite
- خروجی Excel فارسی با لینک قابل کلیک و راست‌به‌چپ

## محدودیت مهم تعامل با دیوار
این نسخه عمداً از استخراج انبوه اطلاعات تماس و ارسال پیام تبلیغاتی سرد در چت دیوار استفاده نمی‌کند. مستندات رسمی «کنار دیوار» تصریح می‌کند ارسال پیام در چت برای تبلیغات یا معرفی خدمات مجاز نیست. پیام در چت فقط در سناریوی خدمت مرتبط با همان معامله، با مجوز برنامه و رضایت/درخواست لازم قابل پیاده‌سازی است. برای اتصال رسمی باید اپلیکیشن در پنل کنار ثبت شود و مجوزهای لازم دریافت شوند.
