# استخراج آگهی املاک دیوار - دزفول

اسکریپت تعاملی استخراج آگهی‌های فروش آپارتمان، ویلایی و زمین در دزفول.

## امکانات
- منوی فینگلیش و ورود تاریخ شمسی
- صفحه‌بندی واقعی مبتنی بر cursor پاسخ دیوار
- استخراج توکن از هر دو ساختار `data.token` و `data.action.payload.token`
- خواندن تاریخ دقیق از بخش «انتشار آگهی» در جزئیات آگهی
- جلوگیری از تکرار با شناسه یکتای آگهی
- پایگاه داده SQLite به‌عنوان منبع اصلی و مقاوم در برابر قطع ناگهانی
- خروجی اکسل فارسی و خلاصه قیمت محله‌ها
- ادامه استخراج از آخرین صفحه و آگهی پردازش‌نشده
- واردکردن خودکار اطلاعات فایل اکسل نسخه قبلی در اولین اجرا

## نصب در ویندوز (PowerShell)
```powershell
cd amlak-divar
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## اجرا
```powershell
python scrape_dezful.py
```

منو:
1. شروع استخراج جدید: بازه تاریخ شمسی و محله اختیاری را تعیین کنید.
2. ادامه استخراج قبلی: فقط تعداد آگهی جدید را وارد کنید.
3. نمایش آمار
4. خروج

نمونه تاریخ: `1405/08/01`

## فایل‌های داده
- پایگاه داده اصلی: `data/amlak.sqlite3`
- وضعیت صفحه‌بندی و ادامه: `data/progress.json`
- خروجی اکسل: `output/dezful_amlak.xlsx`

**نکته:** SQLite منبع اصلی و پایدار داده‌هاست. اگر فایل اکسل هنگام خروجی‌گیری باز باشد، ممکن است ویندوز اجازه جایگزینی آن را ندهد؛ فایل را ببندید و برنامه را دوباره اجرا کنید تا اکسل از پایگاه داده بازسازی شود.

## محدودیت تاریخ
تاریخ فیلتر از متن تاریخ دقیق «انتشار آگهی» در جزئیات دیوار استخراج می‌شود. آگهی‌هایی که دیوار تاریخ دقیقشان را برنگرداند وارد فایل نمی‌شوند و تعدادشان گزارش می‌شود. متن زمان نسبی مانند «دقایقی پیش» به‌عنوان تاریخ دقیق فرض نمی‌شود.

## نکته فنی
API وب دیوار رسمی و تضمین‌شده نیست و ممکن است ساختار آن تغییر کند. از اجرای هم‌زمان چند نمونه اسکریپت خودداری کنید.
